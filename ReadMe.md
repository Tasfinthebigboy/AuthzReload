# AZ Authz Discord Bot

AZ Authz is a multifunctional Discord bot with moderation, utility, automod, fun, AI, and plugin features. It is designed to make server management easier and more engaging.

> [!WARNING]
>
> ## Open Source Discontinuation Notice
> ---
>
> The **4.5-snapshot** version will be the **final fully open-source version** of this project.  
>
> Beginning with **version 4.5** and onward, the project will transition to a **closed-source model** — however,  
> **source code access will remain available exclusively to premium users** through our **official Discord server**.  
>
> All previous versions, including **4.5-snapshot** and earlier, will remain **publicly available** under their current open-source license.  
>
> ⚠️ We sincerely thank everyone who supported and contributed during the open-source phase of this project.

## Command Categories

### 🔨 Moderation Commands

| Command     | Description                   |
| ----------- | ----------------------------- |
| `/ban`      | Ban a member from the server  |
| `/kick`     | Kick a member from the server |
| `/unban`    | Remove a ban from a user      |
| `/purge`    | Bulk delete messages          |
| `/mute`     | Temporarily mute a member     |
| `/unmute`   | Remove a member's mute        |
| `/lock`     | Lock a channel                |
| `/unlock`   | Unlock a channel              |
| `/warn`     | Issue a warning to a user     |
| `/warnings` | View a user's warnings        |
| `/delwarns` | Clear warnings for a user     |

---

### 🛠️ Utility Commands

| Command         | Description                   |
| --------------- | ----------------------------- |
| `/ping`         | Check the bot’s response time |
| `/serverinfo`   | View server information       |
| `/userinfo`     | View user information         |
| `/roleinfo`     | View details of a role        |
| `/channelinfo`  | View details of a channel     |
| `/avatar`       | Get a user’s avatar           |
| `/version`      | Check the bot version         |
| `/createinvite` | Generate an invite link       |

### 🤖 Automod Commands

| Command               | Description                     |
| --------------------- | ------------------------------- |
| `/automod toggle`     | Enable or disable automod       |
| `/automod setlog`     | Set a channel for automod logs  |
| `/automod mode`       | Change automod mode             |
| `/automod ignore`     | Ignore a channel, role, or user |
| `/automod unignore`   | Remove an ignored target        |
| `/automod blockwords` | Manage blocked words            |
| `/automod setlogs`    | Configure automod logging       |

## Installation

1. Clone the repository

```bash
git clone https://github.com/Tasfinthebigboy/AZ-Authz.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the bot

```bash
python main.py
```
